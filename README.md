## 📖 About

🔹 **RimWorld — RunAndGun** is a powerful tool built to help you allow your RimWorld colonists to fire weapons while moving for more dynamic tactical combat. Kiting, retreating, and mobile flanking become viable tactics when colonists can shoot on the move.

🔸 Whether you're a seasoned professional or just getting started, **RimWorld — RunAndGun** delivers a clean, intuitive experience packed with everything you need — right out of the box. ## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Move and Shoot** | Colonists fire their weapons without stopping to aim first |
| **Accuracy Penalty** | Realistic accuracy reduction while moving prevents it from being overpowered |
| **Weapon Whitelist** | Configure which weapon types allow movement during fire |
| **Combat Enhanced** | Tactical retreats and kiting become effective colony defense strategies |
